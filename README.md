StudyOrbit IIT V7.1 — Analysis Refinements

Changes from V7.0:
- Daily Log and Question Bank missing entries are counted as zero in analysis, with later past-date entries reflected when saved.
- Holiday entries retain their original dates in storage. For analytics, their study/practice contributions are split equally between the closest available working dates before and after the holiday (one side if only one exists).
- Time-series graphs include holiday dates as red H markers and interrupt lines over holidays.
- Each graph displays labeled X and Y directional arrows.
- Subject Reality Check includes Correct Questions/hour and a bounded 0–100 Efficiency Index (%) computed solely from study time, attempts and accuracy: rate=correct/time; index=100*rate/(1+rate). This is an index, not a literal mastery percentage. Zero activity=0%; questions with zero logged hours=N/A.
- Preserves V7.0 Stage Performance tables, 7/30-day reports and Extra Source category.
