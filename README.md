# JEE Advanced TRACKER (GitHub Pages)

Upload `index.html` and `.nojekyll` to the root of a GitHub repository.

In repository **Settings → Pages**, select **Deploy from a branch**, **main**, **/(root)**, and save.

The tracker is responsive for mobile, tablet and desktop. It stores progress in the browser's localStorage, **not** in your GitHub account. A different browser/device, private mode, or clearing site data may lose access to that progress. Use the built-in Export JSON backup before moving devices or replacing the existing site.

This is a static client-side page; no build step required.
